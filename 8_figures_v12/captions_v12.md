# captions_v12 (InkBridge v12 figures)
LaTeX-ready; each caption has two sentences. Numbers are formatted from the fig_*_data.csv files by code.

## fig_overview  (file ./figs/fig_overview.pdf, label fig:overview)
InkBridge adds a script by warm adaptation, sends each image by script to the warm-adapted model or the warm backbone, and returns one of $k=3$ samples by Endpoint Consensus Selection. Trajectories are from a selected OUHD-L test unit; colour shows pen time.

## fig_gain  (file ./figs/fig_gain.pdf, label fig:gain)
Warm adaptation raises AIoU on Urdu by $+0.047$ and $+0.059$ over plain fine-tuning on the same 336 units, against $+0.014$ for the source-training control, and direction stays inside its margin. Paired differences with 95\% intervals on 4,406 OUHD-L test units (32 writers; three fine-tuning seeds, two for the control; one warm-stage run per variant).

## fig_retention  (file ./figs/fig_retention.pdf, label fig:retention)
With script routing, AIoU is retained on all six non-Urdu test sets (lowest lower bound $+0.007$, threshold $-0.010$), and direction on UNIPEN-de changes by $-0.072$ and $-0.066$. Paired differences to the leave-target-out backbone with 95\% intervals; $n$ = 500 units each for CASIA-zh, CASIA-en, HPL Tamil and IAM500, 827 for UNIPEN-de (7 writers) and 5,925 for OnHW; three fine-tuning seeds.

## fig_selector  (file ./figs/fig_selector.pdf, label fig:selector)
Endpoint Consensus Selection raises pen-up F1 by $+0.014$ to $+0.027$ and strict order by $+0.013$ to $+0.020$ on Urdu for all five base models. Paired differences to the same base without selection with 95\% intervals on 4,406 OUHD-L test units (32 writers); dashed lines are the selection-gain margins.
