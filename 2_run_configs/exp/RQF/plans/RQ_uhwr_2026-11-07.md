# uhwr research questions v2 — one method for all scripts (7 Nov 2026)

Decided by <author> (7 Nov, ask_user): one method for all scripts; three RQs = its components; RQ2 leads; FM distillation is an arm inside RQ2; bar = beat LUO-FT at the same target fraction AND non-inferior to LUO on every other set; held-out targets German (zero-shot), Tamil, Chinese, English; hard freeze 10 Nov 18Z for all tables (not landed = not assessed). Source of all numbers: uhwr records only (claims ledger 2026-11-07 v 7ba071f8; FMD_PREREG sha 7a71c715; FMDX v1.1). Rules: PREREG_RQ_finalise (sha 04766e97) + amendment A2.

Problem. A stroke-recovery model trained on one script fails on another: Urdu-trained E0 on German UNIPEN-de tau -0.119, direction 0.400; Urdu-free LUO on OUHD-L tau 0.4799, direction 0.5468; IAM-trained TRACE on Urdu lines tau -0.987.

Method (one system). Shared backbone trained without the target script -> warm adaptation (224-px ViT-S/14 student encoder, optional FM feature distillation) -> 1 % target-script addition in one model (SM-R: single checkpoint with replay; SM-A: shared backbone + per-script LoRA via router) -> inference with label-free frame selection (R1d) and label-free order selection (endpoint verifier).

RQ1 (zero-shot component). Can script-agnostic inference — choosing between identity and mirrored frames by sample agreement, with no script label — make the model work on scripts with no training data, without hurting scripts it already handles?
 Evidence: mirror_x on LUO direction 0.5468 -> 0.8687, tau 0.4799 -> 0.6586 [0.6187, 0.6926] (K1 CI-lo bar 0.65 not met); AIoU 0.7117 -> 0.7090. Frame selection itself is unbuilt.
 Reads: R1a-R1c, R1d (A2), German zero-shot cells.

RQ2 (lead; low-resource addition). Does warm adaptation add a new script from 1 % of its data in one model better than fine-tuning at the same fraction, on Urdu and held-out Tamil/Chinese/English, without losing the other scripts — and does FM feature distillation add to it?
 Evidence (single seed): vs plain COMP-p01, NOFM_W AIoU +0.0483 [+0.0462, +0.0506], pen-up +0.0748, strict +0.0267, direction -0.0058; PEINIT_W AIoU +0.0595. Composed (router, two weight sets) NOFM_W and PEINIT_W AIoU CI > 0 vs LUO on all 6 non-Urdu sets. FM arm c-radiov3-h_W minus NOFM_W AIoU -0.0142 (PROMOTED, not FM-ATTRIBUTED). Warm arms lose direction on UNIPEN-de (-0.06 to -0.08, 7 writers). Encoder change and +40k steps confounded until LUOC40.
 Reads: R2a-R2e, SM-R/SM-A (A2), held-out Tamil (R2d), Chinese and English (A2), FM arms (FMD A4.5 / cell F).

RQ3 (test-time component). Does label-free endpoint selection improve stroke order across base models and scripts, and does it stack with RQ1 and RQ2 in the one model?
 Evidence: on COMP-p01 sealed test pen-up +0.0288 [+0.0260, +0.0316], strict +0.0186 [+0.0153, +0.0216], direction n.s.; random-of-3 control null. One base, one script; test read added after validation.
 Reads: R3a, R3b, stacked read (A2).
